# チュール式戦術ボード v0.7.2 — デザイン更新版

元の v0.7.1 の作戦会議・作戦再生機能を維持したまま、画面を整理した版です。外部サーバー不要の単一HTMLで利用できます。

## 使い始める

1. `index.html`（単体配布版のファイル名は `churu_tactical_board_v072.html`）を Chrome / Edge で開きます。
2. 右側の「マップを準備」→「マップ画像を選択」、またはマップ上部の「マップ画像を選択・変更」で背景を読み込みます。
3. 「作戦会議」で味方・敵・特殊駒を配置し、必要に応じて進軍線と時間アクションを設定します。
4. 作戦管理や再生は従来どおり。「マップを大きく」を押すと、画面共有しやすい表示になります。

## 変更点

- アプリ名を「チュール式戦術ボード」に変更。
- ヘッダーから戦場選択、白紙、デモ、画像選択、JSON読み込みボタンを移動。
- 右側に「マップを準備」パネルを追加。背景読み込みを目立たせ、戦場選択・白紙・デモ・JSON読み込みを集約。
- マップ直上にも画像読み込み・変更ボタンを配置。全画面・スマートフォンでもアクセスできます。
- 操作ツールを「駒の追加」「移動・ルート」「説明ツール」「整理」に分類。横にスクロールできます。
- 配色、カード、ボタン、余白、見出し、入力欄など全体的な外観を統一。
- 頻繁に使うマップを初期画面の上部に近づけ、画面共有で表示しやすい配置に変更。
- バージョン番号は画面最下部の控えめなフッターに移動。
- HTML内部の作戦データ形式と保存キーは変更していません。

## 互換性とバックアップ

旧 v0.7.1 と同じJSONデータ形式を維持しています。重要な作戦データは旧版から「JSON保存」しておき、新版の「作戦JSONを開く」から読み込んでください。HTMLファイルの保存先やブラウザの制限により、旧版の自動保存が別ファイルへ直接引き継がれるとは限りません。

## 動作確認

Chromium（1440×900、モバイル相当390×844）で18項目のブラウザテストを実施し、全項目合格。iOS/Android実機は未検証です。確認項目は `TEST_REPORT.md` をご覧ください。
