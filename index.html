マップを準備

ゲーム画面のスクリーンショットを読み込み、作戦図の背景にできます。

1. 部隊の管理

味方 0 / 敵 0

部隊一覧の左端のチェックは複数選択、隣のチェックはマップでの表示です。

味方・敵を追加すると初期位置の指定が始まります。会議中は「✋ 駒を動かす」で仮配置のみ変更できます。各行の 🗑 で部隊を削除できます。地図上では「🗑 アイコン削除」→アイコンをタップ。非表示の部隊は削除対象になりません。

2. 特殊アイコンの管理

0 / 40

味方・敵の部隊数とは別枠。総大将・強敵・井闌車を個別に管理します。

☑ 複数選択・表示切替・名称・色・初期位置・仮移動・進軍線・途中待機・削除に対応。

3. 選択中の駒

駒を追加または選択してください。

4. 待機の設定 操作改善

駒を選択すると待機を設定できます。
「地図で位置指定」→ ルート上をタップ。金色の⏸をドラッグして微調整できます。待機は何箇所でも追加可能です。
